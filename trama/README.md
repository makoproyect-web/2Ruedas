# TRAMA

Proyecto paralelo a 2Ruedas: marca de herramientas de terminación (llanas, espátulas, rodillos y accesorios) para pintores, yeseros y albañiles.

Por ahora es solo la parte visual: una web de presentación de estilo minimalista y premium.

## Archivos

- `index.html`: la web, en un solo archivo. Se abre en cualquier navegador (necesita internet para las fuentes y las librerías).
- `CATALOGO.md`: la lista de piezas con funciones, medidas y variantes.

## Qué tiene la web

- Inicio: una llana de acero peina el enduido a medida que se desliza la página.
- Escena de alisado: una espátula alisa el enduido con el scroll.
- Colección de 28 piezas en 5 familias, con ficha lateral (usos, medidas, variantes).
- Galería horizontal de 6 texturas, cada una con la herramienta que la hace.
- Soluciones: problema de obra → pieza que lo resuelve.
- Contacto para pinturerías y profesionales.

La web no menciona procesos de fabricación ni origen: habla de problemas y soluciones.

## Cómo editar

- Piezas: array `PRODUCTS` dentro de `index.html`.
- Soluciones: array `SOLUTIONS`. Texturas: array `TEXTURES`.
- Contacto: WhatsApp e Instagram marcados "(a definir)".

## Identidad (carpeta `marca/`)

- `identidad.html`: manual de marca (concepto, logo, construcción, usos, colores, tipografía, texturas, aplicaciones y voz).
- Logos en SVG: isotipo, logotipo, firma horizontal y vertical, en grafito y en yeso sobre grafito.
- Concepto: la T de TRAMA es una llana dada vuelta. La placa con su dentado de doce dientes queda arriba y el mango forma el trazo vertical.
